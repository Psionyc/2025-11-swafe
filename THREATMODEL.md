# Critical Threat Model

Swafe's documentation highlights that only account owners and authenticated email holders must be able to trigger account or backup recovery, and that guardian thresholds as well as off-chain secrecy are core invariants.【F:README.md†L127-L200】 The table below focuses on the code paths whose failure would immediately violate those invariants and create critical risk.

| Partisia contract & HTTP router (`contracts/src/lib.rs`, `contracts/src/http/*`) | Owns canonical account state, node configs, and dispatches every off-chain HTTP endpoint for init, association, and reconstruction flows.【F:contracts/src/lib.rs†L20-L134】【F:contracts/src/http/mod.rs†L1-L172】 | Relies on the Partisia runtime, EmailCert verification, the global VDRF public key, and off-chain storage mappings for secrets and guardian shares.【F:contracts/src/lib.rs†L67-L105】【F:contracts/src/http/endpoints/association/upload_msk.rs†L32-L74】 | `update_account` must only accept verified updates, and `/init` must bind a single off-chain secret to its commitment before any association endpoints are usable.【F:contracts/src/lib.rs†L107-L134】【F:contracts/src/http/endpoints/init.rs†L44-L80】 | HTTPS node URLs and high-entropy committed secrets remain hidden, and only owners request recovery as mandated in the spec.【F:contracts/src/lib.rs†L48-L58】【F:README.md†L137-L145】 | The public action `update_account` plus the POST endpoints `/init`, `/association/upload-association`, `/association/get-ss`, `/association/vdrf/eval`, `/reconstruction/upload-share`, and `/reconstruction/get-shares` are all exposed; any bug in their token/commitment checks would let an attacker register rogue nodes, overwrite associations, or harvest guardian shares (which are only protected by the requester’s recovery encryption).【F:contracts/src/http/endpoints/association/upload_msk.rs†L32-L74】【F:contracts/src/http/endpoints/association/get_secret_share.rs†L1-L45】【F:contracts/src/http/endpoints/association/vdrf/eval.rs†L1-L37】【F:contracts/src/http/endpoints/reconstruction/upload_share.rs†L33-L74】【F:contracts/src/http/endpoints/reconstruction/get_shares.rs†L19-L34】 |
